# Blueline Surf & Paddle Co. — "Ride Jupiter" website concept

A single-page website redesign concept, built for presentation purposes.

**Live preview:** https://jasoncolapietro.github.io/blueline-surf-concept/

Includes a live surf and tide panel for Juno Pier (Open-Meteo marine/weather models and NOAA CO-OPS tide predictions, station 8722670), plus interactive shop, rentals, and lesson-booking mockups.

> Independent design concept. Not affiliated with or endorsed by Blueline Surf & Paddle Co. Product names, prices, reviews, and staff shown are illustrative.
